Continuidad C⁰, C¹ y C²

  • C⁰: los tramos se encuentran en el mismo punto: Xᵢ(tᵢ₊₁) = Xᵢ₊₁(tᵢ₊₁), igual para Y. La curva no tiene saltos.
  • C¹: coinciden las primeras derivadas (la tangente): bᵢ + 2cᵢhᵢ + 3dᵢhᵢ² = bᵢ₊₁. No hay esquinas.
  • C²: coinciden las segundas derivadas (la curvatura): 2cᵢ + 6dᵢhᵢ = 2cᵢ₊₁. La curva es suave.
  • Natural: X″ = Y″ = 0 en los dos extremos (c₀ = cₙ = 0).

Fórmulas utilizadas

t₀ = 0 , tᵢ = tᵢ₋₁ + √[(xᵢ − xᵢ₋₁)² + (yᵢ − yᵢ₋₁)²] , hᵢ = tᵢ₊₁ − tᵢ
Xᵢ(t) = aₓ + bₓ(t − tᵢ) + cₓ(t − tᵢ)² + dₓ(t − tᵢ)³ , t ∈ [tᵢ, tᵢ₊₁]
Yᵢ(t) = aᵧ + bᵧ(t − tᵢ) + cᵧ(t − tᵢ)² + dᵧ(t − tᵢ)³ , i = 0, …, n−1
aᵢ = xᵢ (para X) · aᵢ = yᵢ (para Y)
hᵢ₋₁cᵢ₋₁ + 2(hᵢ₋₁ + hᵢ)cᵢ + hᵢcᵢ₊₁ = 3[(aᵢ₊₁ − aᵢ)/hᵢ − (aᵢ − aᵢ₋₁)/hᵢ₋₁] , i = 1, …, n−1
c₀ = cₙ = 0 (frontera natural)
bᵢ = (aᵢ₊₁ − aᵢ)/hᵢ − hᵢ(2cᵢ + cᵢ₊₁)/3 , dᵢ = (cᵢ₊₁ − cᵢ)/(3hᵢ)

El sistema tridiagonal (estrictamente diagonal dominante, por lo que tiene solución única) se resuelve por separado para X(t) e Y(t). La curva se dibuja evaluando los polinomios cúbicos de cada tramo en muchos valores de t; no se usan curvas Bézier ni aproximaciones.
